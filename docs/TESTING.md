# Проверки

## Выполнено локально для 0.1.0

- Release-сборка без ошибок и предупреждений.
- 54 проверки без GPU; 65 с аппаратными тестами GPU, включая загрузку встроенной иконки приложения.
- Геометрия всех четырёх сторон, отрицательные координаты, частичный стык, направление и калибровка.
- Функция затухания и независимость временного сглаживания от FPS.
- Сравнение SIMD-растеризации со скалярной арифметикой, premultiplied alpha, нулевая прозрачность, средняя яркость дизеринга и его неподвижность.
- Сохранение новых настроек, выключение и повторное включение фильтров.
- HLSL compile/dispatch/readback: пространственный порядок цветов, обрезка, чёрные кадры, синтетические повороты и выборка 32/64/128/256.
- На Windows выполнен настоящий захват двух SDR-дисплеев. Сценарий «нижний источник → верхний получатель» проверен визуально.
- Layered-окно создаётся и обновляется; тест сохраняет foreground window. API исключения из захвата возвращает успех.

## Что остаётся ручной проверкой

Полное отсутствие задержек перетаскивания и полос градиента на любой панели; все варианты мыши через наложение; смешанный DPI; натурные повороты; отключение мониторов; сон; блокировка; потеря драйвера; несколько GPU; игры в exclusive-режиме; 4K/60.

Наличие обработчика или успешный вызов API не считается подтверждением всех этих сценариев. См. [чек-лист](MANUAL-TESTS.md).

## Диагностические режимы

```powershell
./portable/EdgeGlow.exe --synthetic-smoke
./portable/EdgeGlow.exe --capture-smoke
./portable/EdgeGlow.exe --benchmark
```

Создают рядом с EXE текстовые отчёты без содержимого экрана. Нужна папка с правом записи. `capture-smoke` сообщает доступность каждого экрана; код завершения сам по себе не заменяет чтение отчёта.

Бенчмарк выполняет реальный захват и постоянно меняющийся искусственный ореол в скрытой поверхности. Это измерение затрат обработки, не тест задержки интерфейса и не нагрузка всего DWM. Низкий CPU в таком тесте не гарантирует отсутствия задержек при перетаскивании.

## CI

GitHub Actions запускает `build.ps1` без `-GpuTests`. Сборка и тесты проверены локально; выполнение workflow на GitHub до загрузки репозитория не проверено. Для GPU-тестов используйте интерактивный Windows-компьютер с Direct3D11, а не обычный облачный runner.
