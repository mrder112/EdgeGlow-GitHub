# Ручная приёмка EdgeGlow

Не отмеченные пункты ниже — план проверки, а не заявление об успешном прохождении.

## Основной сценарий

- [ ] Оба экрана SDR, нижний источник, верхний получатель. Запустить тест: красный слева и синий справа у нижней границы верхнего экрана, затухание вверх.
- [ ] На верхнем экране видны именно текущие обои; смена обоев немедленно видна под свечением.
- [ ] За пределами выбранной глубины изображение не меняется. Нет чёрного прямоугольника, резкой каймы или заметных ступеней градиента.
- [ ] Подать красный/синий рисунок вдоль верхнего края нижнего экрана: позиции цветов сохраняются при настоящем захвате.
- [ ] Чёрный источник гасит свечение без затемнения обоев; тёмные сцены не дают ошибки захвата.
- [ ] Источник не получает оверлей; после включения нет визуальной рекурсии.
- [ ] Клики, колесо, выделение и перетаскивание иконок через ореол работают; фокус не меняется.
- [ ] В режиме рабочего стола Блокнот, пересекающий область свечения, скрывает ореол всего получателя. После перемещения Блокнота эффект возвращается.
- [ ] В дополнительном режиме поверх окон Блокнот окрашивается, но остаётся доступным для ввода.
- [ ] Смена фокуса не меняет закреплённый источник. Автоматический источник меняется только после 500 мс; меню и собственное окно настроек не переключают его.

## Геометрия и настройки

- [ ] Повторить с получателем снизу, слева и справа.
- [ ] Отрицательные координаты, смещённые края, частичный стык, разные разрешения.
- [ ] Масштаб Windows 100/150/200% на разных экранах; ореол совпадает с физическим стыком после изменения DPI.
- [ ] Портретный монитор при повороте 90/270 и перевёрнутый 180: ориентация цветов правильная.
- [ ] Ручной сдвиг и масштаб пары корректны; настройки разных пар независимы.
- [ ] Удалить чёрные полосы четырьмя отступами; неверная обрезка даёт ошибку без падения.
- [ ] Проверить регулировки и лимиты 15/30/60, включая 4K и несколько получателей. Измерить CPU/GPU и реальную частоту.

## Надёжность

- [ ] Щадящий режим: при 5 захватах/с и 30 обновлениях/с переходы непрерывные. Проверить выборку 32/64/128/256 и отсутствие перестановки цветов.
- [ ] Щёлкнуть по рабочему столу другого монитора при включённом отслеживании щелчков: источник и ореол меняются местами. Наведение и щелчки по настройкам не переключают источник.
- [ ] При включённом «Продолжать захват при перемещении окон» ореол сохраняется во время движения; при выключенном — скрывается и возвращается через 200 мс. Ctrl+Shift+F9 переключает опцию и сохраняет её; Ctrl+Shift+F10 только останавливает эффект.
- [ ] Отключение сглаживания даёт мгновенную смену цветов при очередном захвате; включение восстанавливает прежние параметры. Размытие отдельно допускает 0.
- [ ] На тёмных обоях градиент без крупных полос; неподвижный дизеринг не мерцает и не создаёт тёмных краёв.
- [ ] «Сбросить параметры» останавливает эффект и сбрасывает значения, сохраняя выбранные экраны.

- [ ] Быстро отключить горячей клавишей; проверить понятную ошибку при занятом сочетании.
- [ ] Закрыть настройки, открыть из трея, выйти через меню. После выхода нет оверлеев и захвата.
- [ ] Перезапустить: настройки сохранены, эффект выключен. Повреждённый JSON не мешает запуску.
- [ ] Отключить/подключить получатель и источник, поменять разрешение и DPI во время работы.
- [ ] Блокировка/разблокировка, сон/пробуждение, перезапуск Explorer и потеря устройства: окна не зависают, доступный захват восстанавливается.
- [ ] Проверить вызовы исключения из захвата фактическим выбранным backend, а не только код возврата API.
- [ ] Повторить на двух GPU; отдельно проверить полноэкранную игру.
- [ ] HDR-источник даёт явное сообщение; DRM-контент не обходится.
