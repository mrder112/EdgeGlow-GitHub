# EdgeGlow 0.1.0

Первый portable-выпуск для Windows 11 x64: прозрачное свечение между соседними мониторами с сохранением цветов вдоль стыка.

*Иллюстрация работы EdgeGlow. Подсветка создаётся внутри экранов; внешнее освещение стола и стены не является функцией приложения.*

<!-- Следом перетащите assets/release/edgeglow-demo.png. -->

*Визуализация эффекта, не скриншот: цвета нижнего экрана продолжаются мягким ореолом у нижнего края верхнего.*

Включены выбор источника вручную/по активности/щелчку, щадящий режим, настройка плотности и частоты выборки, независимое сглаживание, ручная калибровка, трей и горячие клавиши. Дизеринг уменьшает полосы градиента. Захват во время перемещения окон можно переключать Ctrl+Shift+F9; Ctrl+Shift+F10 останавливает эффект.

**Запуск:** распакуйте `EdgeGlow-portable-win-x64.zip` полностью и откройте `EdgeGlow.exe`. Устанавливать .NET не нужно.

**Ограничения:** SDR; HDR не поддерживается. Режим рабочего стола скрывает весь ореол при перекрытии обычным окном. Ранний выпуск: mixed-DPI, hot-plug, разные GPU и exclusive-игры требуют дальнейшей проверки. Подробности в README.
